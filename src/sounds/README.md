# Sonidos

`crack-1.wav` a `crack-4.wav` son grabaciones reales de un látigo: "Whip crack #1" a "#4" de Joseph Sardin, publicadas en [BigSoundBank](https://bigsoundbank.com/whip-crack-2-s2950.html) con licencia CC0 (dominio público).

Están recortadas para empezar 2 ms antes del chasquido, normalizadas y convertidas a mono de 16 bits y 48 kHz.
